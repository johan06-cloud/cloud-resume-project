01
Cloud Resume Challenge
GitHub ↗

A fully serverless personal resume website deployed on AWS with a real-time visitor counter and automated CI/CD pipeline — built end to end using 7 AWS services.

  • Hosted on AWS S3 as a static site, delivered globally over HTTPS via CloudFront CDN.
  • Visitor counter powered by a Python Lambda function triggered through API Gateway REST API.
  • DynamoDB NoSQL table stores and atomically increments the visitor count on every page load.
  • IAM roles configured with least-privilege access between all services.
  • GitHub Actions CI/CD pipeline auto-deploys on every push to main and invalidates the CloudFront cache.

02
3-Tier VPC Architecture
AWS Console

A production-grade secure 3-tier network architecture on AWS — the same design pattern used by real companies to isolate web, application, and database tiers.

  • Custom VPC (10.0.0.0/16) with 3 subnets across multiple Availability Zones for high availability.
  • EC2 web server running Apache in the public subnet — only entry point from the internet.
  • EC2 app server in a private subnet, accessible only from the web tier via security group rules.
  • RDS MySQL database in an isolated private subnet, accepting connections only from the app tier on port 3306.
  • NAT Gateway for secure outbound internet access from private subnets; Internet Gateway for the public tier.

03
CloudSearch — ECS Fargate
GitHub ↗

A containerized Google-style search web app built with Python/Flask, deployed end-to-end on AWS ECS Fargate using only the AWS CLI — no console clicking, no Terraform.

  • Dockerized using gunicorn as the production WSGI server; Docker image pushed to Amazon ECR.
  • ECS Fargate cluster with task definition and service provisioned entirely via AWS CLI commands.
  • Application Load Balancer with /health route health checks routes traffic to the container on port 5000.
  • Auto Scaling configured from 1 to 3 tasks based on CPU utilization via Application Auto Scaling.
  • Full CI/CD with GitHub Actions using a scoped-down IAM user — every push rebuilds and redeploys automatically.

AWS Monitoring Stack — Terraform
GitHub ↗

A fully automated cloud monitoring system on AWS provisioned with Terraform as Infrastructure as Code — the entire stack is version controlled and reproducible with a single terraform apply.
